# Qavé — אתר היכרויות חינמי

אפליקציית היכרויות חינמית ומלאה המאפשרת חיבור בין משתמשים עם אימות זהות, התאמה גיאוגרפית, שיחות וידאו והתראות בזמן אמת.

## ✨ תכונות עיקריות

- **התחברות חברתית**: כניסה באמצעות Google או Facebook, או הרשמה עצמאית.
- **אימות זהות**: אימות חד-פעמי באמצעות קוד שנשלח ל-SMS או לדוא"ל (OTP בן 6 ספרות).
- **התאמה גיאוגרפית**: הצגת פרופילים לפי מרחק פיזי מהמשתמש, עם תגיות עיר ומרחק בק"מ.
- **ממשק Swipe**: גריפת כרטיסיות (Drag & Drop) ימינה ללייק ושמאלה לדילוג, עם אנימציות חלקות.
- **התראות בזמן אמת**: קבלת התראות חיות על צפיות בפרופיל, לייקים, הודעות והתאמות חדשות (Toasts).
- **צ'אט ושיחות וידאו**: מערכת צ'אט מלאה עם תגובות אוטומטיות, וממשק שיחת וידאו עם בקרות מיקרופון, מצלמה וניתוק שיחה.
- **פרופיל מאומת**: תג "מאומת" למשתמשים שעברו אימות, ואינדיקציית סטטוס "מחובר/ת".

## 🎨 עיצוב

האפליקציה מעוצבת בפלטת צבעים של רוז/ורוד (Rose) עם עומק ויזואלי, צללים רכים, פינות מעוגלות, ואנימציות פריימר-מושן ליצירת חווית משתמש נעימה ומודרנית. הממשק כולו בעברית ותומך בכיוון RTL.

## 🛠 טכנולוגיות

- **React 19** + **TypeScript**
- **Tailwind CSS** לעיצוב
- **Framer Motion** לאנימציות
- **Sonner** להתראות Toast
- **shadcn/ui** לקומפוננטות UI
